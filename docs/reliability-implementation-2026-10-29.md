## 已实现范围

1. 受限编辑：新增 `powerpoint.edit/v1` 与独立 CLI，支持精准文字修改、
   明确的字体/文字样式/几何修改、追加文本框和页面。绑定原稿哈希及严格引用，
   验证目标的冻结属性、非目标对象及整个包的差异；临时 PPTX 通过后才原子替换。
   输出 `powerpoint.edit-proof/v1`，范围证明与视觉审阅状态分开。
2. 文本替换：保留原始 runs、链接和未命中文字的格式；插入内容使用首个命中字符的
   格式。跨字段、显式换行和段落的拼接替换不支持。
3. 几何检查：新增 `powerpoint.geometry/v1`，通过现有 group 坐标变换检查叶对象；
   记录越界、近乎完全遮挡、需要视觉确认的旋转/翻转边界。默认只告警，
   build 在渲染前保存报告，qa 对当前版本重算；支持模板页映射和原有问题识别。
4. 公共字体模块：创建、模板填充和受限字体编辑共享字体写入；
   探测实际字体解析、替代和指定字符覆盖。没有自动安装字体。
5. 可选设计计划：新增 `powerpoint.design/v1`，记录目标、受众、品牌约束和逐页目的、
   重点、页面类型、密度及必须保留的文字；`--design` 接入编译、生成和验收。
   配色/字体字段记录设计意图，不自动覆盖模板样式。
6. 更新 skill 入口、操作参考、README 和版本标记；既有执行接口继续使用。
   本次未复制外部参考包的代码或文档。

详细操作见 [受限编辑、几何与字体](../references/constrained-editing.md)、
[逐页设计规划](../references/design-planning.md)。

## Desktop / Windows 待验收

本轮没有操作 Hermes Desktop 或 Windows PowerPoint，不能宣称产品端完整验收通过。
可在既有 Desktop 用例之后追加以下场景；输入与历史答案仍应隔离：

| 场景 | 提示内容 | 独立验收 |
| --- | --- | --- |
| 只改字体 | 修复指定文本框中文字体，文字、位置、颜色不变 | proof 只允许字体变化；Windows 文字可编辑且无缺字 |
| 精准数字 | 只将指定页面的 150 改为 180 | 命中次数准确；其他文本、图表、媒体和页面不变 |
| 混合格式 | 在包含粗体、常规字及超链接的跨-run词组中替换 | 插入文字取首命中格式；未命中文字和链接保留 |
| 增补一页 | 保留全部原页，最后增加一页说明 | 原页次序与对象不变；新增页可编辑、事实有依据 |
| 模板告警 | 含出血/旋转装饰模板制作新稿 | 原有与新增告警分别记录；视觉审阅核对实际影响 |
| 设计保留项 | 设计计划要求某页保留指定数字和单位 | 删除任一保留项应导致内容检查失败，备注不能代替正文 |

图表数据变更、图片替换、删除和重排仍使用已有 CLI，本批新 scope contract
尚未覆盖这些操作。编辑性和数字正确性仍需原有 inventory/read-back 检查。
原生流程图及 PDF 高保真重建保持为后续独立扩展，本次未宣称实现。
